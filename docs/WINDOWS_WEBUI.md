# JavSP Windows 本地工作台

## 启动和退出

双击 `Start-WebUI.cmd`。等待浏览器打开 `http://127.0.0.1:8765/`；不要关闭随后显示的命令窗口。界面仅供本机使用，不要将端口转发到局域网或互联网。关闭命令窗口会结束工作台；如果任务正在运行，先在工作台点击停止并等待完成，再关闭窗口。强制停止可能留下部分整理结果，不会自动回滚。

程序和运行时均在此目录，现有旧版程序可保留作为回退。启动失败时请检查端口 8765 是否已被其他程序占用。Windows 网络盘符需要在启动工作台的当前用户会话中可访问。

## 整理文件

扫描目录已从迁移配置读取，请确认后勾选风险确认并启动。相对输出路径（默认以 `#整理完成` 开头）相对于扫描目录。程序可能移动或硬链接视频，还可能创建或覆盖 NFO、封面和剧照；即使关闭移动，也会在原目录写入图片和 NFO。建议先在单独的测试目录用少量测试文件核实命名和结果。远程挂载或网盘可能不支持原子替换、硬链接、重命名等操作；失败或断连不会自动撤销已完成的操作。

同一时刻只运行一个任务；界面运行日志仅保存在当前服务进程内，新任务或服务退出后不保留。视频移动或硬链接完成后会追加记录到程序目录的 `FileMove.log`，其中包含本地完整路径，请妥善保管。任务显示的退出码为 0 并不能证明每个已配置的数据源都成功，请检查日志。停止任务可能留下部分文件。

## 配置和代理

界面提供代理、最小视频大小、普通与 FC2 数据源顺序、移动和跳过 NFO 的快速设置，也可直接编辑 `config.yml`。快速设置先生成预览、不会立即保存；生成预览会重新格式化 YAML 并移除注释，确认后再点击保存。若配置在编辑期间被其他窗口或程序修改，保存会被拒绝，请先另存当前编辑内容再重新加载。保存时会进行结构、正则和命名占位符检查，但无法保证网络、权限或每个数据源有效。原 `config.ini` 不会自动覆盖，也不能直接当作新格式使用。迁移结果请重点核对文件命名、输出目录及翻译选项；旧版“中文标题优先”没有直接对应设置。

`network.proxy_server` 为 `null` 时程序没有显式设置代理；底层请求库仍可能使用 Windows 系统代理。若希望显式通过运行中的 FlClash，可设置为 `http://127.0.0.1:6123`；FlClash 停止或端口变化后该设置会使网络请求失败。更换策略组可能影响其他使用同一策略的程序。系统代理与站点的地区限制、登录和访问挑战也会影响抓取结果。

JavDB 需要登录时默认不会读取浏览器 Cookie。仅在了解并同意程序读取本机浏览器中 JavDB 登录凭据后，才可在 `crawler` 下添加 `javdb_browser_cookies: true`；该选项启用后程序可能向 JavDB 发送这些凭据。敏感配置可能包含翻译密钥；`config.yml` 和运行期临时配置不要分享。临时配置在正常任务结束后删除，强制结束系统或进程可能使其残留。

FANZA 新页面通过非官方网页接口读取元数据，该接口和访问条件可能变化；JavBus、JAVLibrary 等站点可能要求验证或限制地区。单个站点访问失败不代表视频会自动成功整理。
