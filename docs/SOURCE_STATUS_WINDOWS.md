## 使用注意

- 未显式设置代理不一定等于直连：Windows 系统代理和上级路由分流仍可能参与。FlClash 的 `http://127.0.0.1:6123` 只有在它运行并监听时才可使用。
- 更换代理节点或区域可能影响同一策略组的其他应用；不要禁用 TLS 验证或将控制器、订阅链接和密钥公开。
- 多个来源会汇总信息，但某个来源受限、标题错误或封面下载失败仍可能影响结果。先使用测试目录并检查输出；任务不会自动回滚。
- JavSP 当前在后台非交互运行，不会替用户完成网站的年龄验证、登录或验证码。
